Life Weeks Tracker

Your personal weekly journal for capturing achievements, memories, and progress in every week of life. Track your journey with meaningful entries, trips, experiences, and daily progress.

Getting Started

Set your date of birth once using the top controls. You can change it later with the Change DOB button.

Add Weekly Highlights

  1. Click any week tile in the grid.
  2. Enter your highlights in the text area.
  3. Mark the week as important if it deserves special emphasis.
  4. Attach files to the week using the file picker.
  5. Save your changes with the Save Highlights button.

Tips & Tricks

  • Write about trips and travel experiences to create memories.
  • Attach photos and documents to weeks for visual storytelling.
  • Use the Important flag for milestone weeks or special moments.
  • Review past weeks regularly to reflect on your growth.
  • Export your data monthly as a backup for safety.
  • Search previous weeks to find specific events or achievements.
  • Use the Secure Folder for private thoughts and confidential notes.

Search & Filter

Use the search box to find weeks by highlight text. Toggle between all weeks and remaining weeks with Show All Weeks.

Export & Print

Use Export to back up your data as JSON and Import to restore it later.

Use Print Highlights to open a printable report of saved highlights and save it as PDF.

Secure Folder

The Folder feature lets you store private notes and attachments behind a password and recovery questions.
